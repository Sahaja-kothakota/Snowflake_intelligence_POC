# Building a Snowflake Intelligence POC: Step-by-Step Guide

This repository contains a proof of concept (POC) demonstrating how to build Snowflake Intelligence using Snowflake Cortex capabilities. The POC showcases how natural language analytics, semantic modeling, search, and agents can be combined to explore retail sales and customer data.

The solution uses five tables from Snowflake’s TPCDS sample data—Customer, Customer Address, Customer Demographics, Item, and Sales—to create a dummy customer analytics database. A semantic model is defined using a YAML file and deployed in Cortex Analyst, enabling users to query data using natural language without writing SQL. Cortex Search is used to index product data for discovery, and Cortex Agents are configured to automate insights and workflows.

This POC is designed to help understand the end-to-end setup of Snowflake Intelligence, from environment configuration to building analyst-ready semantic models and intelligent agents.
